# Codex Agent Handover

## Objective
State original user objective and intended final result.

## Current status
State exactly where work stands now.

## Completed work
Record completed investigation and implementation.

## Files changed
List changed/uncommitted files and relevant changes.

## Commands and tests run
Record important commands, outcomes, exit codes, log paths, and meaningful output summaries.

## Current failures or blockers
Record failing tests, errors, unanswered questions, environmental blockers.

## Decisions and assumptions
Record constraints and decisions another agent must preserve.

## Exact next steps
Ordered continuation plan with concrete files and commands.

## Risks and warnings
Unsafe operations to avoid, fragile areas, credentials concerns, possible regressions.

## Repository state
Relevant `git status --short`; summarize `git diff --stat` when Git exists.

## Last updated
ISO 8601 local timestamp.
